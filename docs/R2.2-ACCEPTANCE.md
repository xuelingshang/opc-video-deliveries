## Windows PowerShell 5.1 验收步骤（Founder，约 10 分钟）

1. 从仓库下载 `r2.2/` 文件夹（GitHub 网页 → Code → Download ZIP，解压后取 `r2.2`）放到桌面。
2. 双击 `01-双击下载全部视频.cmd`：
   - 应显示“没有新的交付视频”，第一行不应出现“不是内部或外部命令”；中文显示正常。
3. 双击 `管理员-测试沙盒下载.cmd`：
   - 应下载 `D:\OPC-DELIVERIES\2099-12-31\TEST-0002\` 与 `TEST-0004\`（或当时存在的 TEST 编号），每个文件夹 4 个文件，能播放 MP4。
4. 再双击一次 `管理员-测试沙盒下载.cmd`：应全部“跳过”。
5. 下载中途拔网线再插上、再双击：应接着下载并完成。
6. 拍下第 2–5 步的黑窗口。全部符合即可标记 Windows PASS。
7. 验收后：Actions → “TEST delivery release” → Run workflow → `action=cleanup`；删除 `D:\OPC-DELIVERIES\2099-12-31` 和 `_已完成记录\TEST-*.json`。
